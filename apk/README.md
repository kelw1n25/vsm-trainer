# Android-приложение (APK)

`vsm-trainer.apk` — готовое приложение для телефона на Android 8.0+. Работает с развёрнутым сервером
https://vsm-trainer.onrender.com — тем же, что и веб-версия, поэтому прогресс, рейтинг и уведомления общие.

1. Скачайте `vsm-trainer.apk` на телефон и откройте файл.
2. Разрешите установку из этого источника (APK подписан отладочным ключом — ставится без магазина).
3. Вход: проводник `100001` / `demo2026`, инструктор `900001` / `demo2026`. Данные синтетические.

Первое открытие после простоя сервера — до минуты (бесплатный хостинг засыпает).
Собрано из `android/` командой `./gradlew assembleHosted`; исходники — в этом же репозитории.
