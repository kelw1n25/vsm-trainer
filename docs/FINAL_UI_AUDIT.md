# Итоговый аудит интерфейса: сайт → Android

Эталон — веб-клиент `frontend/` на ширине телефона 390 pt. Исходный аудит — [MOBILE_UI_AUDIT.md](MOBILE_UI_AUDIT.md),
карта и чек-листы экранов — [MOBILE_SCREEN_MAP.md](MOBILE_SCREEN_MAP.md).

## Как проверялось

| Платформа | Сборка и тесты | Визуальная проверка |
|-----------|----------------|---------------------|
| Android | `assembleDebug`, 31 JVM/Robolectric-тест (в т. ч. 13 тестов `StoryEngine`) — Docker `android/ci` | эмулятор Pixel (1080 × 2400), живой backend, учётки 100002 и 900001; светлая и тёмная тема; `logcat` без пропуска кадров на длинных экранах |

Бизнес-логики в клиентах нет: исход шага, таймер, шкалы, XP, ачивки, рейтинг и рекомендации считает сервер.
Клиенты хранят только то же, что сайт в `localStorage`: тему, «Уменьшить анимацию», место в новелле, журнал,
виденные сцены, «Авто» и «Звук».

## Дизайн-система

| Элемент сайта | Android | Совпадение |
|---------------|---------|------------|
| Цвета `:root` и `html[data-theme="dark"]` (≈50 токенов) | `design/Color.kt` → `LightColors/DarkColors` | 1:1, те же HEX и прозрачности |
| Шрифт Manrope 400–800 (SIL OFL 1.1) | `res/font/manrope_*.ttf` | 1:1 |
| Шкала текста, высота строки, трекинг | `VsmType` | 1:1 (CSS px = pt/sp) |
| Радиусы 20 / 16 / 14 / 12, тень `0 8 30 rgba(24,64,140,.06)` | `Shapes`, `Modifier.vsmShadow()` | 1:1 |
| Кнопки, теги, чипы, вкладки, переключатель, поле ввода, бейджи | `design/components/*` | 1:1 |
| Иконки (стрелка, шевроны, солнце, луна, метка, сетка), логотип | векторные drawable по SVG сайта | 1:1 |
| Графики: шкалы, XP по неделям, радар | `design/components/Charts.kt` (Canvas) | та же геометрия, сетка, цвета и анимация роста 0.9 с |
| Персонажи, фоны сцен, иллюстрации, поезд hero, фото | те же WebP в `drawable-nodpi` | 1:1 — картинки сняты с самого сайта |
| Аватар сотрудника | своё фото в круге или `Canvas` по координатам SVG сайта | 1:1 — фото с сервера или вектор с деталями из конструктора |
| Анимации: `rise-in`, `page-in`, `AnimatedNumber`, `sprite-in/talk`, реакции эмоций, `delta-float`, печать текста | Compose Animatable / graphicsLayer | те же длительности и кривая `cubic-bezier(.2,.7,.2,1)` |
| «Уменьшить анимацию» | настройка | как `html[data-reduce-motion]` |

## Быстродействие (Android, эмулятор Pixel 7, Apple M3)

Замер `dumpsys gfxinfo`: прокрутка главной и сценариев, затем пять реплик новеллы с печатью текста.

| Конфигурация | «Тормозящие» кадры | Кадр, медиана / 95 % |
|--------------|--------------------|----------------------|
| debug, эмулятор без видеокарты (программная графика) | 98 % | 1050 / 2500 мс |
| debug, эмулятор с видеокартой (`-gpu host`) | 2 % | 20 / 32 мс |
| **demo** (R8, профили Compose), видеокарта, фоновая распаковка картинок | 0–1 % | 19 / 21 мс |
| demo, новелла | 0 % | 18 / 21 мс |

Графика не упрощалась: те же тени, размытия, затемнение неговорящего и анимации. Что сделано в приложении:
картинки распаковываются в фоне и кэшируются (раньше фон сцены 1290 × 2796 распаковывался на главном
потоке), сборка `demo` — оптимизации release с локальным backend. Эмулятор после многих часов работы
и переустановок деградирует (сборка мусора системы — секунды): помогает перезапуск.

## Доступность

- TalkBack: у кнопок и переключателей — подписи и состояния («Тёмная тема — включена»), заголовки
  помечены как заголовки, KPI и строки рейтинга читаются одной фразой, декоративные картинки скрыты,
  реплика новеллы читается целиком с действием «Далее», таймер озвучивает остаток.
- Касание — не меньше 48 dp у интерактивных элементов.
- Масштаб шрифта Android учитывается через sp.
- «Уменьшить анимацию» отключает переходы, печать текста и эффекты появления.

## Найдено и исправлено при проверке

| Что | Где | Исправление |
|-----|-----|-------------|
| Экран развития истории строился 28 с (вложенные intrinsic-измерения в дереве) | Android | линия ветки рисуется поверх уже измеренной колонки |
| Пропуск кадров на длинных экранах из-за анимации точки «онлайн» | Android | анимация читается только в слое отрисовки |
| Тёмные значки статус-бара в тёмной теме | Android | стиль системных панелей следует теме приложения |
| Тёмная заставка при запуске светлой темы, чужая иконка | Android | фон окна и сплэш — цвет `--bg`, иконка — логотип сайта |
| «Сценарии» не подсвечивались на странице сценария | Android | подсветка как у NavLink сайта |
| Подпись «Справочник» обрезалась, маркеры списков висели | Android | ширина пункта по длине подписи; компонент `Bullet` с висячим отступом |
| Подписи радара рвались посреди слова и заходили на сетку | Android | шире подписи, меньше радиус, подпись над/под вершиной |
| Последняя подпись графика шкал обрезалась справа | Android | отступ под подпись |
| Длинное название компетенции в карточке команды рвалось посреди слова | Android | колонке значения — больше места |
| После выхода и входа другим сотрудником в меню аватара оставались имя и роль прежнего (без «Команды» у инструктора) | Android | имя и роль читаются из текущей сессии, счётчик уведомлений обновляется при входе |
| Кнопка «Продолжить» читала незавершённое прохождение, которое никто не сохранял; на сайте её нет | Android | убрана вместе с хранилищем — сервер сам возвращает незавершённое прохождение |
