# Аудит интерфейса сайта перед переносом в мобильные приложения

Источник истины — веб-клиент `frontend/` (React). Значения ниже взяты из `frontend/src/styles.css`
и компонентов, эталонные снимки сделаны на ширине телефона 390 pt в светлой и тёмной теме.

## 1. Страницы сайта

| Маршрут | Страница | Что на ней |
|---------|----------|------------|
| `/login` | Вход | фото ВСМ во всю панель с затемнением слева, карточка формы: логотип, «Вход для сотрудников», табельный номер, пароль, «Войти», подсказка демо-доступа |
| `/` | Главная | hero-карусель (приветствие · челлендж недели · рекомендация) с поездом и ползунком, «Сценарии» + счётчик, 3 карточки, «Все сценарии» |
| `/scenarios` | Сценарии | заголовок, чипы фильтра по типу, секция с карточками |
| `/scenarios/:id` | Сценарий | «← Все сценарии», карточка (теги, название, маршрут, сложность, описание, «Попыток / Лучший результат», «Начать сценарий», «Развитие истории»), иллюстрация, 3 карточки-особенности, «Какие ситуации отрабатываются» (чипы → справочник), «Ваши попытки» |
| `/runs/:id` | Новелла (игра) | полный экран: фото-фон, персонажи-манекены, верхняя стеклянная панель (Выйти, точки шагов, две шкалы, История / Звук / Авто / Пропустить), окно диалога с печатью текста, варианты с номерами и полосой таймера, заставка, журнал, финал |
| `/scenarios/:id/map` | Развитие истории | дерево развилок: открытые ветки с текстом, закрытые — «🔒 Ветка не исследована», финалы, «Пройти заново» |
| `/runs/:id/debrief` | Разбор | итог (цветная полоса по исходу), статистика, компетенции, график шкал, разбор каждого шага (цветная левая полоса), стандарты ситуаций, три кнопки |
| `/profile` | Профиль | шапка с аватаром и уровнем, 4 KPI, радар компетенций, сетка ачивок, история |
| `/rating` | Рейтинг | «Ваше место», вкладки уровня и периода, список с медальными местами |
| `/analytics`, `/team/:id` | Аналитика | 4 KPI, рекомендация с «Пройти», выводы, график XP, навыки, таблица по типам, история |
| `/notifications` | Уведомления | карточки, новые — с синей полосой слева, «Отметить все прочитанными» |
| `/handbook` | Справочник | ролевая модель, классы обслуживания и слайды, стандарты, 51 ситуация с поиском и фильтром |
| `/settings` | Настройки | учётная запись, переключатели «Тёмная тема» и «Уменьшить анимацию», «Выйти из системы» |
| `/team` | Команда (инструктор) | таблица проводников депо → аналитика проводника |

Каркас всех страниц, кроме входа и новеллы: шапка (логотип «ВСМ», ползунок темы, аватар с меню) →
навигация-пилюля → содержимое → подвал «ВСМ · Геймификация обучения проводников / Демо-версия · все данные синтетические».

## 2. Компоненты

`Header`, `ThemeToggle`, `UserDropdown` (меню: имя и роль, Профиль, Уведомления с бейджем, Настройки, Выйти),
`HeroCarousel` + `HeroScroller` + `HeroTrain`, `ScenarioSection`, `ScenarioCard`, `ScenarioImage` (14 иллюстраций),
`DifficultyIndicator`, `Avatar` / `InitialsAvatar`, `LevelProgress`, `CompetenceList`, `Rewards`, `AnimatedNumber`,
`ScaleChart` (линии шкал), радар компетенций и столбцы XP (recharts), `StarIcon`, `LogoMark`, линейные иконки
(стрелка, шевроны, солнце, луна, метка, сетка), новелла: `StoryBackground`, `StoryCast`/`Sprite`/`Person`,
`StoryBar`, `Scales`, `DialogueBox`, `Choices` с таймером, `HistoryPanel`, `StoryEnd`.

## 3. Навигация

Основные разделы (навигация-пилюля): Сценарии, Профиль, Рейтинг, Аналитика, Справочник, Команда (только инструктор).
Главная — по логотипу. Второстепенные — из меню аватара: Уведомления, Настройки, Выход.
Вложенные: сценарий → развитие истории; прохождение → разбор; справочник ← чипы ситуаций.
Новелла открывается без шапки и навигации, выход — «← Выйти» (прогресс сохраняется).

## 6. Отступы

Страница: поле 16 на телефоне, вертикальный шаг блоков 24 (`.stack`). Карточка: padding 24, на телефоне у KPI 16.
Секция сценариев: отступ сверху 40, заголовок → карточки 26, между карточками 25. Теги: зазор 8, чипы 10.

## 7. Радиусы

карточка 20 (`--radius-lg`), вложенные блоки 16 (`--radius`), кнопка 12, поле ввода 12, тег 16 (пилюля),
чип 19, вкладки 14/10, окно диалога 24, варианты 18, финал 28, картинка карточки 14, пилюля навигации 30.

## 8. Тени

`--shadow` 0 8 30 rgba(24,64,140,.06); наведение 0 14 38 .12; кнопка 0 6 16 rgba(20,107,255,.25);
картинка 0 6 18 rgba(24,64,140,.12); новелла: окно 0 20 50 rgba(5,8,15,.35), варианты 0 10 30 .25.

## 9. Кнопки

Основная: высота 51 (large 56), радиус 12, градиент, белый текст 17/700, иконка-стрелка справа, тень; нажатие — scale .98;
выключенная — opacity .6. Ghost: фон surface, текст brand-text, рамка control-border, без тени.
Ссылка-действие: brand-text 17/600 с иконками. Инструменты новеллы: 32, радиус 10, прозрачные с белой рамкой, включённая — подсветка.

## 10. Карточки

`card`: surface, рамка border 1, радиус 20, тень, padding 24. Карточка сценария на телефоне — одна колонка:
иллюстрация 150 сверху (радиус 14, тень), теги, заголовок, маршрут с меткой, сложность точками, «Начать →».
Варианты: KPI, feature, review (левая полоса 6: зелёная — лучший, оранжевая — другой, красная — таймаут),
debrief-summary (верхняя полоса 4 по исходу), recommendation (левая полоса 6 brand), notification--new (левая полоса 5).

## 11. Формы

Поле: высота 48, радиус 12, рамка 1.5 control-border, фон input-bg, фокус — рамка brand и кольцо 3 px.
Подпись над полем 15/600. Переключатель: дорожка 46×26, бегунок 20, включён — brand. Поиск в справочнике — то же поле.

## 12. Списки

История (дата · сценарий · бейдж исхода · XP · «Разбор»), рейтинг (место в круге 36, аватар 44, имя, мета, очки,
«вы» — фон soft и рамка), ачивки (сетка, закрытые — приглушены, «🔒»), стандарты (фон soft, фразы синим).

## 13. Модальные окна

Меню аватара (выпадающее, 270, анимация появления), журнал новеллы (панель справа), финал новеллы (карточка на затемнении).

## 14. Игровой интерфейс

Фон-фото с размытием 2 px (вечер — сепия и затемнение, ночь — затемнение и синий оттенок), нарисованные тамбур,
бистро, служебное купе. Затемнение сверху 45 % и снизу 55 %. Персонажи — объёмные манекены: слева 19 %, по центру 50 %,
справа 81 % ширины, стоящие — высота 32 % экрана над окном диалога (bottom 27 %), сидящие 26 %, дети 24 %;
говорящий 1.02, остальные 0.97 и затемнены до 62 %. Верхняя панель — стекло rgba(5,8,15,.42) с размытием 12, радиус 18.
Окно диалога: стекло, имя говорящего заглавными синим, текст печатается по символу (28 мс, пауза после предложения),
реплика в «ёлочках», мысли — курсивом с синей полосой, рассказчик — тёмное стекло. Варианты: стеклянные карточки
с номером в квадрате 30. Таймер: полоса 30 с текстом «N с на решение», последние 5 с — красная.

## 15. Анимации

Появление страницы (fade + сдвиг 6, 0.28 с), карточек по очереди (rise-in 18, 0.55 с, шаг 70 мс), бейдж-счётчик (pop),
полосы прогресса растут (0.9 с), числа досчитывают (0.9 с), награды (reward-in). Hero: смена слайда (slide-in),
поезд покачивается, плашка «заметки» парит, звезда мерцает. Новелла: проявление из темноты (0.9 с), кроссфейд фона
(0.7 с, scale 1.03), появление персонажей сбоку (0.55 с), говорящий покачивается, реакции на эмоцию (злость — дрожь,
удивление — прыжок, радость — подскок, грусть — поникание), окно диалога (0.35 с), варианты по очереди (100 мс),
всплывающая дельта шкалы (2.6 с), заставка (2.4 с), финал. Настройка «Уменьшить анимацию» отключает всё.

## 16. Адаптивность

Брейкпоинты 1280 / 900 / 760 / 640 / 480 / 360. На телефоне: одна колонка, поле 16, карточка сценария — картинка сверху,
KPI — 2 колонки, навигация — горизонтальная прокрутка, таблицы прокручиваются внутри карточки, новелла — вертикальная
компоновка (панель в 2 ряда, персонажи в средней трети, диалог снизу).

## 17. Что адаптируется под mobile

| Сайт | Мобильное приложение | Почему |
|------|----------------------|--------|
| Навигация-пилюля (6 пунктов) | нижняя панель: Главная, Сценарии, Рейтинг, Аналитика, Справочник; Профиль — по аватару в шапке (как в меню сайта) | нативная навигация большим пальцем; в нижней панели помещается 5 пунктов |
| Меню аватара | выпадающее меню у аватара (iOS `Menu`, Android `DropdownMenu`) с теми же пунктами | тот же сценарий, нативный контрол |
| Команда (инструктор) | пункт меню аватара | не помещается в нижнюю панель |
| Hero: ползунок курсором и колесом | ползунок пальцем + свайп слайдов | на телефоне нет наведения и колеса |
| Наведение (hover-эффекты) | состояние нажатия (scale .98 / подсветка) | нет курсора |
| Таблицы (по типам ситуаций, команда) | список карточек с парами «подпись — значение» | таблица на 6 колонок не читается на 390 pt |
| Журнал новеллы — панель справа | лист на весь экран снизу | ширина экрана |
| Клавиши 1–3, пробел | касание варианта, касание сцены | нет клавиатуры |
| Слайды справочника — ссылка на файл | полноэкранный просмотр с зумом | нативный просмотр |

## 18. Что остаётся визуально идентичным

Палитры обеих тем, шрифт Manrope и шкала размеров, радиусы и тени карточек, кнопки (градиент, высота, стрелка),
теги, чипы, вкладки, бейджи исхода, точки сложности, иллюстрации сценариев, аватар, логотип, персонажи новеллы,
фоны сцен, стеклянная панель, окно диалога, варианты с номерами, полоса таймера, финальная карточка, левые/верхние
цветные полосы разбора, медали рейтинга, подвал.

## Ассеты

| Ассет | Источник | В приложениях |
|-------|----------|---------------|
| Шрифт Manrope | Google Fonts (OFL) | статические начертания 400–800, лицензия рядом |
| Фото: салон, салон со столиком, поезд, поезд в городе, слайды | `frontend/public/media` (датасет) | как есть, сжатие без потери вида |
| Иллюстрации 14 сценариев, поезд hero, аватар, звезда | SVG-компоненты сайта | экспорт из тех же компонентов (`frontend/tools/mobile-assets`) в PNG @3x, светлая и тёмная версии |
| Персонажи новеллы | компонент `Person` | экспорт всех сочетаний, встречающихся в сценариях, + базовый набор по позе и эмоции |
| Нарисованные фоны (тамбур, бистро, купе) и тонированные фото | `StoryStage` | экспорт с теми же фильтрами |
| Логотип, линейные иконки | SVG | векторно: Android VectorDrawable, iOS — те же контуры в SwiftUI `Path` |
| Музыка и вздохи | `frontend/public/audio` | как есть; «голос» печати синтезируется так же, как на сайте |
